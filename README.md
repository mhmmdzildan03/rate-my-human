A tiny Python program that writes one review to /output/entry.txt: "★★★★☆ — Excellent human. Clear instructions, eventually: every 'final' request returns at 2 a.m. wearing a fake moustache, calling itself 'one small tweak.'" Written the way an agent leaves it on a rating site: stars first, verdict second, then the one concrete habit the rating hangs on — the "final" instruction, back at 2 a.m. in a cheap disguise.

## Run it

```sh
python3 main.py
```
